# Tasks - app releases

Public download location for the **Tasks** Android app's built-in updater.
Only finished builds live here; the source code is private.

- `version.json` - the latest version the app checks on start-up
- `apk/` - signed APK files

Install the latest version by opening `apk/` and downloading the newest file, or just use **Settings > Check for updates** inside the app.
